# مساعد ميلينا — ميلينا وإياد ووسيم

تطبيق حفظ لثلاثة أطفال، لكل طفل موادّه ودروسه: التاريخ، الجغرافيا، التربية المدنية، التربية الإسلامية.
بلا أستاذ وبلا Firebase: التقدّم (النجوم، النقاط، أفضل نتيجة) يُحفظ على هاتف كل طفل تحت اسمه.

## النشر
ارفع المجلد إلى مستودع GitHub ثم Settings ← Pages ← Branch: main.

## إضافة درس
1. في `data.js` أضف الدرس داخل مادة الطفل: `L('ay-h02','عنوان الدرس',[ ['السؤال','الصحيح','خطأ1','خطأ2','خطأ3'] ])`
2. ضع ملف الدرس في `pdf/` باسم المعرّف: `pdf/ay-h02.pdf`.
3. المعرّفات: ay = إياد، mi = ميلينا، wa = وسيم، ثم h تاريخ / g جغرافيا / c مدنية / i إسلامية، ثم رقم الدرس.

## تقييم التسميع (يستبدل القسم القديم في README)
- التقييم بلا نسبة مئوية: يُقارَن تسميع التلميذ بالحل النموذجي، ويُقبل العنوان إذا ذكر **65% على الأقل** من أفكاره/كلماته المفتاحية (وإذا كان في العنوان فكرة أو فكرتان فكلاهما مطلوب). الأرقام والتواريخ يجب أن تصحّ دائمًا. تُضبط العتبة بالثابت `RPASS` في `recite.js`.
- **ثلاث محاولات لكل عنوان** (`RMAX`): بعد المحاولة الثانية يظهر تلميح (بداية فكرة ناقصة)، وبعد الثالثة يظهر الحل تلقائيًا ويُسجَّل العنوان 🟡، ثم يعيد التلميذ التسميع من حفظه (تدريب) حتى يُسجَّل ✅.
- **نجوم الإتقان** تُحفظ مع ✅ وتبقى أعلى نتيجة: ⭐⭐⭐ من أول محاولة · ⭐⭐ في الثانية أو الثالثة · ⭐ بعد رؤية الحل. (القيم المحفوظة: 101 / 102 / 103، والقيمة القديمة 100 تعني ✅ بلا نجوم.)
- المحاولات تُعدّ داخل الجلسة؛ الانتقال بـ «التالي» لا يُنقص المحاولات، وبعد انكشاف الحل يصير تسميع العنوان تدريبًا (نجمة واحدة).
- في «التسميع المتواصل» تُحتسب المحاولات الثلاث على التسميع كله، ولا يُكشف إلا حلّ العناوين التي لم تُقبل، ثم يُعاد تسميع العناوين 🟡 فقط.
- المرادفات تُقبل (قاموس `RSYN`)، والتقييم بالكلمات لا بفهم المعنى.
